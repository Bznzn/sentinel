# 国内安全漏洞订阅源推荐（可提取结构化数据）

> 本文档只推荐包含 CVE、厂商、产品、CVSS 等结构化信息的订阅源

## 订阅原则

✅ **必须包含以下信息之一：**
- CVE 编号
- 厂商名称 + 产品名称
- CVSS 评分
- 漏洞影响版本

❌ **不订阅：**
- 安全新闻资讯
- 技术教程文章
- 行业分析报告
- 会议活动信息

---

## 1. 官方漏洞数据库（推荐）

### NVD - 美国国家漏洞数据库
- **类型**: CVE 官方数据源
- **订阅方式**: 你的 NVD Fetcher 已实现

- **网站**: https://www.cnvd.org.cn/
