## 第1步：理解整体架构（10分钟）

### 阅读材料
打开 `README.md`，重点关注系统架构图部分。

### 核心概念
Sentinel 是一个基于多 Agent 协作的安全事件智能分析平台，主要特点：

1. **5个Agent串联处理管道**
   - 数据采集 → 智能提取 → 去重过滤 → 风险评估 → 解决方案生成
   - 每个Agent专注一个任务，协同完成事件分析

2. **Supervisor多Agent路由**
   - 根据用户问题智能分发到专业Agent
   - 支持事件查询、威胁分析、报告生成等场景

3. **RAG检索增强**
   - Milvus向量数据库存储事件向量
   - 豆包Embedding生成1024维向量
   - 相似度检索增强LLM生成质量

### 架构图理解
```
前端(React) ←→ 后端(Go) ←→ AI层(5个Agent + Supervisor)
                    ↓
            数据层(MySQL + Milvus)
```

## 第2步：了解核心业务流程（15分钟）

### 阅读材料
打开 `docs/项目使用文档.md` 第5章功能模块详解。

### 5个Agent协作流程

| 阶段 | Agent | 技术实现 | 输入 | 输出 |
|------|-------|---------|------|------|
| 1 | 数据采集Agent | MySQL查询 | 数据库 | 最多10条新事件 |
| 2 | 智能提取Agent | DeepSeek V3 | 原始事件 | 结构化信息(标题/CVE/严重程度) |
| 3 | 去重过滤Agent | MD5哈希 | 提取后事件 | 去重后事件列表 |
| 4 | 风险评估Agent | DeepSeek V3 | 去重事件 | 风险评分(0-100) |
| 5 | 解决方案Agent | ReAct + RAG | 高危事件 | 处置方案 |

### 关键技术点

**ReAct推理框架**
- Agent自主决定调用哪些工具
- 最多25步工具调用
- 结合思考(Reasoning)和行动(Acting)

**RAG检索增强生成**
- 从Milvus检索历史相似事件
- 从知识库检索修复参考文档
- 增强LLM生成的准确性

**SSE流式通信**
- 实时展示Agent思考过程
- 前端逐字显示AI输出
- 提升用户体验

## 第3步：熟悉技术栈（5分钟）

### 后端技术栈

| 组件 | 技术 | 用途 |
|------|------|------|
| 语言 | Go 1.24 | 高性能后端服务 |
| Web框架 | GoFrame v2 | HTTP服务和路由 |
| ORM | GORM v1.25 | 数据库操作 |

| LLM | DeepSeek V3 | 智能提取、风险评估、推理 |
| Embedding | 豆包Doubao | 文本向量化(1024维) |
| 向量数据库 | Milvus v2.5.10 | 语义检索 |
| 关系数据库 | MySQL 8.0 | 事件存储 |

### 前端技术栈

| 组件 | 技术 | 用途 |
|------|------|------|
| 框架 | React 18 + TypeScript 5.6 | UI开发 |
| 构建工具 | Vite 6.0 | 快速构建 |

| 图表 | ECharts 5.4 | 数据可视化 |

### 为什么选择这些技术？

- **Go**: 高并发、高性能，适合AI推理密集型任务

- **DeepSeek V3**: 性价比高的大模型，推理能力强
- **Milvus**: 开源向量数据库，支持大规模向量检索
- **React + Vite**: 现代化前端开发体验


### 启动步骤

**1. 启动Milvus向量数据库**
```bash
cd manifest/docker
docker-compose up -d

# 等待90秒让Milvus完全启动
sleep 90

# 验证Milvus状态
docker-compose ps
```

**2. 启动MySQL数据库**
```bash
cd ../..  # 回到项目根目录
docker-compose up -d mysql

# 验证MySQL连接
mysql -h 127.0.0.1 -P 3307 -u root -p
# 密码: sentinel123
```

**3. 配置后端**
```bash
# 复制配置文件
cp manifest/config/config.yaml manifest/config/config.local.yaml

# 编辑配置文件（重要！）
# 需要修改以下配置项：
# - ds_think_chat_model.api_key: 你的Ark API Key
# - doubao_embedding_model.api_key: 你的Ark API Key
# - database.pass: sentinel123
# - file_dir: 知识库文档目录的绝对路径
```

**4. 启动后端服务**
```bash
# 安装依赖
go mod download

# 启动服务
go run main.go

# 看到以下输出表示成功：
# Server started at :6872
# Milvus connected successfully
# MySQL connected successfully
```

**5. 启动前端服务**
```bash
# 新开一个终端窗口
cd web

# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 访问 http://localhost:3001
```

```go
type Agent struct {

    Model  LLM
    Tools  []Tool

// ReAct推理循环
func (a *Agent) Run(ctx context.Context, input string) {
    for step := 0; step < maxSteps; step++ {
        // 1. 思考下一步行动
        action := a.Think(ctx, input)

        // 2. 执行工具调用
        result := a.Act(ctx, action)

        // 3. 判断是否完成
        if result.IsFinished {
            break
        }
    }
}
```

## 关键概念速查

### ReAct推理
- **定义**: Reasoning + Acting，结合思考和行动的推理框架
- **流程**: 思考 → 行动 → 观察 → 思考 → ...
- **优势**: Agent可以自主决策，灵活调用工具

### RAG检索增强生成
- **定义**: Retrieval-Augmented Generation
- **流程**: 用户查询 → 向量检索 → 注入上下文 → LLM生成
- **优势**: 减少幻觉，提供事实依据

### SSE流式通信
- **定义**: Server-Sent Events，服务器推送事件
- **优势**: 实时性好，单向通信，比WebSocket轻量
- **格式**: `data: {...}\n\n`

### Supervisor模式
- **定义**: 多Agent协作的路由器
- **职责**: 分析用户意图，分发到专业Agent
- **实现**: 使用LLM进行意图分类

## 常见问题

**Q: 没有Ark API Key怎么办？**
A: 访问 https://console.volcengine.com/ark 注册账号，开通DeepSeek V3和豆包Embedding权限。

**Q: 可以使用其他LLM吗？**
A: 可以，修改 `internal/ai/models/` 实现新的LLM适配器即可。

**Q: 如何添加新的Agent？**
A: 在 `internal/ai/agent/` 创建新Agent，在 `internal/workflow/` 编排流程。

**Q: 如何添加新的工具？**
A: 在 `internal/ai/tools/` 实现工具接口，在Agent配置中注册。

**Q: 前端如何调试SSE？**
A: 使用浏览器开发者工具的Network标签，查看EventStream类型的请求。
